PRACTICE RULE
-------------

Before moving to the next topic, try to solve around 70–80% of the tasks
without looking at solutions.

For each coding problem:
1. Understand the input.
2. Decide the expected output.
3. Write the logic in plain English.
4. Code it yourself.
5. Test with normal cases.
6. Test with edge cases.
7. Only then look for a solution if you are stuck.
