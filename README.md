# Striver DSA 2026

## How to run
Open any `.cpp` file and press **Ctrl+Shift+B**.
- Input is read from `input.txt` (root)
- Output is written to `output.txt` (root)
- The compiled `.exe` goes into `bin/` (ignored by git)

## Naming convention
- One problem per file, in camelCase: `secondLargest.cpp`, `isPalindrome.cpp`
- Optional number prefix to keep order: `01_helloWorld.cpp`
- Put a topic's notes next to its code, e.g. `notes.txt` inside the topic folder
- Remove a folder's `.gitkeep` once the folder has real files
